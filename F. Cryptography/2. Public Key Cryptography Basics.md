
## Introduction 
| Security Goal       | Real-World Example                                    | Cyber-World Problem                                                     |
| ------------------- | ----------------------------------------------------- | ----------------------------------------------------------------------- |
| **Authentication**  | You see/hear the person → confirm their identity      | How do you know the texter is who they claim to be?                     |
| **Authenticity**    | You know the words come from your partner, not others | How do you verify the message genuinely came from the claimed sender?   |
| **Integrity**       | Nothing changes their words across the table          | How do you ensure data wasn't altered while travelling across networks? |
| **Confidentiality** | Low voice, private seating → only they hear you       | How do you stop unauthorized parties from eavesdropping?                |

###### Cryptography Solutions 
| Type           | Key Name                 | Primary Role                                                                  |
| -------------- | ------------------------ | ----------------------------------------------------------------------------- |
| **Symmetric**  | Private Key Cryptography | Confidentiality (encrypting data)                                             |
| **Asymmetric** | Public Key Cryptography  | Authentication, Authenticity, Integrity (verifying identity & unaltered data) |


## Common use of Asymmetric Encryption 
| Analogy     | Cryptographic System              |
| ----------- | --------------------------------- |
| Secret Code | Symmetric Encryption Cipher & Key |
| Lock        | Public Key                        |
| Lock's Key  | Private Key                       |
**How it works:**
1. Ask friend for their lock (public key).
    
2. Put the secret code (symmetric key) in an indestructible box and lock it with their lock.
    
3. Send the locked box over the open.
    
4. Only friend can unlock it with their private key.
    
5. Now both can share the secret code and can communicate privately at high speed
