### Command 
- Echo ---> output text that provide
- whoami ---> user's currently logged in as 


### Interacting with File System
- ls ---> listing
- cd  ---> change directory 
- cat ---> concatenate
- pwd ---> print working directory   (finding out the full path of current directory)



### Searching for Files
- find 
    example:
    - find -name passwords.txt
    - find -name *.txt

- Grep ---> search the contents of files for specific values that we are looking for    
    Example:
    - grep "81.143.211.90" access.log
- Grep -R ( recursively ) ---> multiple files inside a directory / or to search recursively through all files and subdirectories 
    Example:
    - grep -R "PRETTY_NAME" /etc/




### Introduction to Shell Operators 
- & operator 
    - allows to run commands in the background terminal


- && 
    - allows to combine multiple commands together in one line terminal
    Example: 
    - `command 1 && command2`

- >  ( redirector )
    - take a output from a command ( using a cat to output a file ) and direct it elsewhere
    Example:
    - echo hey > welcome 
    - cat welcome 
    output:     hey 

- >> 
    - same function *>* operator but appends the output rather than replacing ( nothing is overwritten )
    Example:
    - echo hello >> welcome
    - cat >> welcome 
    output:  hey 
          welcome
