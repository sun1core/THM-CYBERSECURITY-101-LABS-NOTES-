###### Understanding the file permission in numeric format 
```
rwxrwxrwx
```
First 3 ---> Owner ---> rwx
next 3 ---> Group ---> rwx 
last 3 ---> others ---> rwx 

- r  = read      ---> 4
- w = write    ---> 2
- x = execute ---> 1


## Common Directories 
- /etc   ( *etcetera* )
    - common place location to store filesystem that are used by operating system
    - in files stores password for each user to encrypted formatting called sha512

- /var ( *variable data* ) 
    - folders store data that is frequently accessed or written by services or applications running on system.  ( Databases )

- /root 
    - data in a directory such as "/home/root" by default 

- /tmp   ( *temporary* )
    - volatile and used to store data that is only needed to accessed once or twice 
    - once the computer is restart, contents and folders are clear-out
    - for *penetration* it serves as a good place to store things like our enumeration scripts.
