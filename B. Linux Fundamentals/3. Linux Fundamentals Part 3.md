

### Terminal Text Editors 
1. nano  ( *create or edit a file using nano* )
    Example:
```
	nano filename
```
	- ctrl + x for exit nano 
- some of the features on nano :
    - searching for the text 
    - copying and pasting
    - jumping to a line number
    - finding out what line number you are on 


1. VIM    ( *advanced text editor* )
    Benefits of VIM'S
    - customizable - modify the keyboard shortcuts
    - syntax highlighting - writing or maintaining code, popular for software developers
    - Vim work on all terminals or nano may not be installed

*Some of the signal*
- SIGTERM - Kill process, allow to do some cleanup tasks beforehand 
- SIGKILL - kill process, don't cleanup after the fact 
- SIGSTOP - stop/suspend a process


###### Systemctl
- interact with the systemd process/daemon
    - code format *systemctl [option] [service]*
    - Example: *systemctl start apache2*
         ###### 5 options with systemctl:
         - start 
         - stop
         - enable 
         - disable 
         - status
