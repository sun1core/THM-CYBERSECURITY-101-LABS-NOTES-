
### Shell Scripting and Components
- CLI that lets you interact with the Linux OS by typing commands.

**Check Current Shell**
```
echo $SHELL
```
*Example Output;*
```
/bin/bash
```

**List Available Shells**
- Linux stores available login shells in:
```
cat /etc/shells
```

**Switch Shell**
```
zsh
```

***Change Default Shell Permanently***
```
chsh -s /usr/bin/zsh
```

### Shell Scripting and Components
- a file containing multiple shell commands that are executed together

**Main Purpose: *Automate Repetitive Tasks***
- bash scripts normally use `.sh` extension
- bash uses `#!/bin/bash` as the shebang
- used in Linux administration, cyber-security, CTFs and Automation.

##### Main Components
|Component|Purpose|Example|
|---|---|---|
|**Shebang**|Defines the interpreter|`#!/bin/bash`|
|**Variables**|Store and reuse values|`name="John"`|
|**Input**|Takes user input|`read name`|
|**Output**|Displays information|`echo "Hello"`|
|**Loops**|Repeats commands|`for i in {1..10}`|
|**Conditions**|Makes decisions|`if [ "$name" = "John" ]`|
|**Comments**|Explain code; ignored by shell|`# This is a comment`|

#### Create & Run a script 
1. **CREATE**
```
nano script.sh
```

2. **Add Shebang**
```
#!/bin/bash
```

3. **Give Execute Permission**
```
chmod +x script.sh
```

4. **Run**
```
./script.sh
```
- ./ means execute the script from the current directory.


##### Variables
- store data and reuse it
```
name="John"
echo "$name"
```
**User Input**
```
read name
echo "Welcome, $name"
```

##### Loops
- used to repeat tasks
```
for i in {1..10}
do
    echo $i
done
```

##### Conditional Statements
- used for decision-making
```
if [ "$name" = "Stewart" ]; then
    echo "Authorized"
else
    echo "Not authorized"
fi
```
**logic**
```
Condition TRUE  → if block runs
Condition FALSE → else block runs
```

## Locker Script ( THM )


```
#!/bin/bash

# Variables
username=""
companyname=""
pin=""

# Ask for details
for i in {1..3}; do
    if [ "$i" -eq 1 ]; then
        echo "Enter your Username:"
        read username
    elif [ "$i" -eq 2 ]; then
        echo "Enter your Company name:"
        read companyname
    else
        echo "Enter your PIN:"
        read pin
    fi
done

# Check credentials
if [ "$username" = "John" ] && [ "$companyname" = "Tryhackme" ] && [ "$pin" = "7385" ]; then
    echo "Authentication Successful. You can now access your locker, John."
else
    echo "Authentication Denied!!"
fi
```
