### Network Troubleshooting 

```
ipconfig
```
---> show our Ip address, sub netmask, default gateway.

```
ipconfig/all
```
---< for more information like view DNS servers and confirm that DHCP enabled.


###### Network Troubleshooting 
```
ping target_name ( or ip address )
```
---> ICMP packet or listen for response
---> also, checking a server access 


```
tracert target_name ( or Ip Address )
```
---> trace network route traversed to reach target

```
nslookup example.com ( or ip address )
```
---> host or domain return its Ip address
---> retrieve the name server 

```
netstat
```
---> displays the current network connections and listening ports 
     opt for the following;  `-abon`
      `-a` → All connections + listening ports
      `-b` → Programs using connections/ports
      `-o` → Shows PID
      `-n` → Shows numeric IPs + ports

### File Disk Management 

```
dir
```
- view all the directories

```
dir /a ---> display hidden files 
dir /s ---> display all files in current directory and subdirectory 
```

```
tree
```
- visually represent al child directories

```
- cd target_directory ---> change directory 
- cd .. ---> go up one level
- mkdir target_directory ---> make directory 
- rmdir directory_name ---> remove directory 

```

*also, we can use wildcard character ( * ) refer to multiple files.*



### Task and Process Management
```
- tasklist  ---> running process 
- tasklist /? ---> Help
- tasklist /FI "imagename eq sshd.exe"  ---> serach task related to "sshd.exe" also, "/FI" filter image 
- taskkill /PID target_pid ---> terminate any task using process id ( PID )
```





### Conclusion 
- `chkdsk`: Checks disk for errors and bad sectors.
- `driverquery`: Lists installed device drivers.
- `sfc /scannow`: Scans and repairs corrupted system files.
- `more file.txt`:display text files 
- `command | more`: views long output page by page.
