### PowerShell
- tool for task automation and configuration management.


### Power Shell Basics 
```
Get-Command 
```
---> Finds available PowerShell commands and shows their details.

```
Get-Command -CommandType "Function"
```
 ---> Lists all available PowerShell functions.
 
```
Get-Help Get-Date 
```
---> Shows help information for Get-Date.

```
Get-Alias
```
 ---> Shows aliases and the commands they represent.
 
```
Find-Module -Name "PowerShell*" 
```
---> Finds PowerShell Gallery modules starting with PowerShell.

```
Install-Module -Name "PowerShellGet"
```
 ---> Installs the PowerShell Get module.


### Navigating the Filesystem and  working with files 
```
Get-ChildItem 
```
---> Lists files and folders in a directory.

```
Set-Location -Path ".\Documents"
```
---> Moves into the Documents directory.

```
New-Item -Path ".\captain-cabin\captain-wardrobe" -ItemType "Directory"
```
---> Creates a new directory (folder) named captain-wardrobe inside captain-cabin.

```
Remove-Item -Path ".\captain-cabin\captain-wardrobe\captain-boots.txt"
```
---> Deletes the captain-boots.txt file, from the specified directory.

```
Copy-Item -Path .\captain-cabin\captain-hat.txt -Destination .\captain-cabin\captain-hat2.txt
```
---> Copies captain-hat.txt and creates a new copy named captain-hat2.txt in the same folder.

```
Get-Content -Path ".\captain-hat.txt"
```
---> Displays the contents (text) of captain-hat.txt in the PowerShell terminal.



### Piping, Filtering and Sorting Data

**PIPING ---> `Command 1 | Command 2` ---> Output of Command 1 becomes input for Command 2.**

```
Get-ChildItem | Sort-Object Length
```
--> Lists files and folders, then sorts them by size (Length).
```
     `Get-ChildItem` ---> retrieves the files
     `Sort-Object` ---> sorts by their Length (size) property
```

```
Get-ChildItem | Where-Object -Property "Extension" -eq ".txt" 
```
---> Lists only the .txt files in the current directory.
```
      `where-object` ---> Filters the result
      `-Property Extension` ---> checks the file extension 
```

#### Table: 
|Operator|Short meaning|
|---|---|
|`-ne`|Not equal|
|`-gt`|Greater than|
|`-ge`|Greater than or equal|
|`-lt`|Less than|
|`-le`|Less than or equal|

```
Get-ChildItem | Where-Object -Property "Name" -like "ship*" 
```
---> Finds files and folders whose name starts with ship. 

```
     -Property Name ---> checks the item name 
     -Like ship* ---> matches the name start with ship.
```


```
Get-ChildItem | Select-Object Name,Length 
```
---> Lists files and folders and displays only their Name and Size (Length).
```
     select-object ---> select specifies properties 
```

```
Get-ChildItem | Sort-Object Length -Descending | Select-Object -First 1 
```
---> Finds the largest file/item in the current directory.
```
    Sort-Object Length -Descending ---> sorts by size, largest first 
    Select-Object -First 1 ---> selects only the first item 
```


```
Select-String -Path ".\captain-hat.txt" -Pattern "hat"
```
---> Searches the file for lines containing the word hat.
```
     `select-string` ---> searches text in files 

```





### System and Network Information 
```
Get-ComputerInfo 
```
---> Shows detailed information about the computer. Like; BIOS details, hardware specifications, OS information

```
Get-LocalUser
```
 ---> Lists the local user accounts on the computer.
 
```
Get-NetIPConfiguration
```
 ---> Shows the computer's IP and network configuration.
 
```
Get-NetIPAddress
```
 ---> Displays the IP addresses assigned to the computer's network interfaces.


### Real-Time System Analysis 
```
Get-Process
```
 ---> Lists the currently running processes/programs on the computer.
 
```
Get-Service
```
---> Lists the services installed on the computer and shows their current status. 

```
Get-NetTCPConnection
```
 ---> Displays the computer's current TCP network connections.
     like, local IP address & port, Remote IP address & port, connection state, PID

```
Get-FileHash -Path .\ship-flag.txt 
```
---> Calculates a hash value for the ship-flag.txt file. or generate hashes and verify its integrity




### Scripting 
- automating multiple tasks by putting commands into a script 

**Blue Team**
- Analyze logs
- Detect suspicious activity
- Find indicators of compromise (IOCs)
- Investigate incidents
- Scan systems for threats
- Automate security checks


**Red Team**
- Enumerate systems
- Gather information
- Execute commands remotely
- Automate penetration-testing tasks
- Test security control

**System Administrator**
- Manage computers
- Configure systems
- Check system health
- Apply security policies
- Automate administrative tasks
- Manage many computers remotely



***Invoke Command***
- execute PowerShell commands on  remote computers.  --- 
    Your computer → Remote computer → Execute command → Return result
