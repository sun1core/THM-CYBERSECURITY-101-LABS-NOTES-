
### TLS ( Transport Layer Security )
- for secure web communication 
- main Purpose of TLS:
    - Confidentiality → prevents others from reading data 
    - Integrity → prevents others from modifying data
- TLS allows secure client-server communication over an insecure network 
- at the transport later at the OSI model 

###### TLS Certificate 
- obtain to prove its identity 
- **CSR ( Certificate Signing Request )** : request submitted to a certificate authority ( CA ).
- **Self-signed Certificate** : signed by the server itself; do not prove authenticity no trusted third party ( CA ) verified it.



### HTTP & HTTPS
**HTTP**
- TCP Port 80, 
- http traffic is sent in cleartext → attackers can intercept or read it 
- Before requesting a web page:
    - DNS resolution → domain → IP Address 
    - TCP 3-way handshake
    - HTTP communication → like `GET /HTTP1.1`
    - TCP connection termination 

**HTTPS ( HTTP over TLS )
- TCP port 443

**HTTPS Security** 
- TLS encrypt HTTP traffic 
- packet capture application data instead of readable HTTP contents
-  Without the required decryption key, captured traffic appears as unreadable data.
- With the key available, tools like Wireshark can decrypt and display the HTTP requests.

### SSH 
- **TELNET:** Remote administration but sends traffic in cleartext → login credentials can be intercepted.  TCP 23
- **SSH (Secure Shell):** Developed by Tatu Ylonen to provide secure remote access. TCP 22

***BENEFITS OF SSH***
- *Secure Authentication* → password, public-key, 2FA authentication
- *confidentiality* → encrypts traffic and helps protect again eavesdropping or MITM.
- *Integrity* → Ensures data is not modified during transmission
- *Tunneling* → Routes other protocols through a secure SSH tunnel.
- *X11 Forwarding* → Allows graphical applications to run remotely.
#### COMMANDS
```
ssh username@hostname
```
- username same as a local user

```
ssh 192.168.124.148 -X
```
- For Graphical Application

### VPN ( Virtual Private Network )
###### How VPN Works

1. VPN client connects to VPN server.
2. A secure VPN tunnel is established.
3. Client encrypts traffic and sends it through the tunnel.
4. VPN server decrypts the traffic and forwards it.

***Benefits Of VPN***
- ENCRYPTION
- Remote access
- IP Masking
- Location Change 
- IP Visibility


> [!NOTE] 
> Device → VPN Client  → Encrypted Tunnel → VPN Server → Internet
