
### Nmap Discovery: Who is online
###### Target specification:
- *IP Range*: 192.168.0.1 - 10  **- (Dash)**
- *Subnet*: 192.168.0.1/24 → scans 256 IPs ( 192.168.0.0–255 )  **( CIDR )
- *Hostname*: example.com

###### Commands 
|Option|Purpose|
|---|---|
|`-sn`|Discover **live hosts**|
|`-sL`|**List targets** without scanning|
|`-PS`|TCP SYN discovery|
|`-PA`|TCP ACK discovery|
|`-PU`|UDP discovery|

##### Local Network 
- directly connected through ethernet/wi-fi
- sees the MAC Address
- MAC address reveal the network-card/device vendor, which may help identify the device type

##### Remote Network 
- has one or more routers between you and the target
- used host method discovery like: ICMP Echo, ICMP Timestamp, TCP SYN, TCP ACK 

```
nmap -sn 192.168.66.0/24
nmap -sL 192.168.0.1/24
```

> [!NOTE] Title
> `-sn` tells WHO is online, not WHAT services they are running.




### Port Scanning: Who is Listening
- find network services listening on a host 
- services listen on TCP or UDP 

###### TCP Connect Scan  -sT  ( Complete Handshake )
- performs the complete TCP 3-way handshake
- if port open connection succeed 
- Nmap then closes the connection 
- if port closed then target sends like → RST/RST-ACK


###### SYN Scan -sS   ( Stealth Scan )
- sends SYN
- port open → receives SYN/ACK 
- produces fewer connection logs than `-sT`

###### UDP Scan  -sU  ( UDP Scan)
- connectionless → not TCP-style handshake 
- Closed UDP ports may respond with ICMP port Unreachable 
- common DUP Services like; DNS, DHCP, NTP, SNMP, VoIP

***Controlling Ports***

| Option      | Meaning                            |
| ----------- | ---------------------------------- |
| `-F`        | Fast → scans 100 most common ports |
| `-p10-1024` | Scan ports 10–1024                 |
| `-p1-25`    | Scan ports 1–25                    |
| `-p1-1023`  | Scan well-known ports              |
| `-p-`       | Scan all 65,535 ports              |

```
nmap -sT <target>     → TCP Connect Scan
nmap -sS <target>     → TCP SYN/Stealth Scan
nmap -sU <target>     → UDP Scan
nmap -F <target>      → Top 100 ports
nmap -p- <target>     → All 65,535 ports
nmap -p1-1023 <target> → Well-known ports
```


> [!NOTE] Title
> `-sn` → Who is ONLINE?
`-sS/-sT/-sU` → What is LISTENING?



### Version Detection: Extract More Information

###### OS Detection
- detects or guesses the target OS
- uses various network indicators/fingerprinting also, not 100% accurate 
```
 nmap -O <target>
```

###### Service and Version Detection 
- finds which service is running on an open port
- attempts to identify the service version 
```
nmap -sS -sV <target>
```

###### Short 
| Option | Purpose                          |
| ------ | -------------------------------- |
| `-O`   | OS detection                     |
| `-sV`  | Service + version detection      |
| `-A`   | OS + version + traceroute + more |
| `-Pn`  | Scan even if host appears down   |

### Timing: How Fast is Fast
**Timing**

| Option | Name       | Speed     |
| ------ | ---------- | --------- |
| `-T0`  | Paranoid   |  Slowest  |
| `-T1`  | Sneaky     | Very slow |
| `-T2`  | Polite     | Slow      |
| `-T3`  | Normal     | Default   |
| `-T4`  | Aggressive | Fast      |
| `-T5`  | Insane     | Fastest   |
Higher `-T` number → FASTER scan even, easier for IDS/security tools to detect 

###### Parallelism 
- controls number of TCP/UDP probes running simultaneously
```
--min-parallelism <num>
--max-parallelism <num>
```
**Example**;
```
nmap --min-rate 100 <target>
```

###### Packet Rate 
- controls number of packets sent per second 
```
--min-rate <number>
--max-rate <number>
```
**Example**
```
nmap --min-rate 100 <target>
```
- whole scan not one individual host 

###### Host Timeout 
- sets the maximum time Nmap will wait for a target host 
- for slow host or slow networks

```
nmap --host-timeout 30s <target>
```

**NOTE**

| Option              | Meaning                         |
| ------------------- | ------------------------------- |
| `-T0` → `-T5`       | Scan timing/speed               |
| `--min-parallelism` | Minimum simultaneous probes     |
| `--max-parallelism` | Maximum simultaneous probes     |
| `--min-rate`        | Minimum packets/second          |
| `--max-rate`        | Maximum packets/second          |
| `--host-timeout`    | Maximum waiting time for a host |


### OUTPUT: Controlling what you see
#### Verbose Output/ Verbosity
- shows more real-time information while Nmap is scanning
```
nmap -v <target>
```

**Increase Verbosity**
```
-v       → Verbose
-vv      → More verbose
-vvvv    → Very detailed
-v2      → Verbosity level 2
-v4      → Verbosity level 4
```

#### Debugging ( -d )
- provides much more detailed debugging information than `-v`
```
nmap -d <target>
```

**Increase Debugging**
```
-dd
-d3
-d9    → Maximum debugging level
```

***Example:***
```
nmap -sS 192.168.139.1 -oA gateway
```

$$Short Note$$
```
-v          → Verbose output
-vv         → More verbose
-d          → Debugging
-d9         → Maximum debugging

-oN file    → Normal output
-oX file    → XML output
-oG file    → Grepable output
-oA name    → All major formats
```
