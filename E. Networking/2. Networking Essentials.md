
### DHCP ( Dynamic Host Configuration Protocol )
- automatically gives a device the network settings its needs
- laptop can connect to WI-FI without manually entering an IP address

```
tshark -r DHCP-G5000.pcap -n
```

###### What DHCP Provides 
- IP address + subnet mask 
- Gateway/router → connects to other network
- DNS Server → converts domain names to IP address

###### DHCP Uses
- UDP 67 → DHCP server
- UDP 68 → DHCP client

 ###### DORA Process
1. Discover 
- Client broadcasts: “Is there a DHCP server?”

2. Offer   
- DHCP server replies: “You can use this IP.”

3. Request  
- Client says: “I accept this IP.”

4. Acknowledge  
- Server confirms: “IP assigned to you.”

**D → O → R → A**  
**Discover → Offer → Request → Acknowledge**


>Final Result
> device receives an IP + subnet mask + gateway + DNS, allowing it to communicate on the network and access the Internet.


### ARP ( Address Resolution Protocol ): Bridging Layer3 Addressing to Layer2 Addressing 

- Find mac address of a device when already known its IP
```
tshark -r arp.pcapng -Nn
tcpdump -r arp.pcapng -n -v
```

###### Why ARP is needed
- IP address = identifies the device at layer 3.
- Mac Address = identifies the device at the local layer 2.
- to send an IP packet over the ethernet or Wi-Fi, the sender needs the destination mac address.

###### ARP Process
1. ARP Request 
Sender broadcasts:

> Who has `192.168.66.1`?

- Destination MAC: `ff:ff:ff:ff:ff:ff`
- Everyone on the local network receives it.

2. ARP Reply 
The device owning that IP responds:

> `192.168.66.1` is at `44:df:65:d8:fe:6c`.

Now the sender knows the MAC address and can send Ethernet frames directly.

###### Example;
`IP → MAC`
`192.168.66.1 → 44:df:65:d8:fe:6c`


### ICMP: Troubleshooting Networks

- used for network testing, diagnostics, and error reporting

#### PING 
- used to check whether a target is reachable and measure RTT ( Round-Trip Time )
**Process**
`Your PC → ICMP Echo Request → Target`  
`Your PC ← ICMP Echo Reply ← Target`
- shows response time and packet loss
- `ping -c 4` → sends 4 packets on Linux 
- No reply doesn't always mean the device is offline, a firewall may block ICMP.

#### Traceroute 
- Linux : `traceroute`
- Windows: `tracert`
- shows the routers ( hops ) between the destination
- uses TTL ( Time To Live )
```
Your PC → Router 1 → Router 2 → Router 3 → Target
```
- each router decreases the TTL by 1

***When TTL reaches 0, the router***
1. drops the packet
2. sends an ICMP time exceeded ( type X ) message back.
- allows traceroute to discover each router 
> **Important Note**
- *** → router didn't respond or router was blocked 
- route can change when run traceroute again
- TTL's "time" number of router hops, not seconds

|Tool|Purpose|ICMP|
|---|---|---|
|**ping**|Check connectivity + RTT|Echo Request/Reply|
|**traceroute**|Find the route/routers|Time Exceeded|


### Routing 
- *Routing* → finding the path
- *Routing Protocols* → help routers learn routes and chose where packets should go
- process of deciding which path a packet should take form the source network to the destination network 
- Example; **Network 1 → Router → Router → Network 2***


==TABLE==

|Protocol|Easy Meaning|
|---|---|
|**OSPF**|Finds efficient paths using a map of the network topology|
|**EIGRP**|Cisco protocol that chooses paths based on factors such as bandwidth and delay|
|**BGP**|Routes traffic **between different networks/ASes**; the main routing protocol of the Internet|
|**RIP**|Chooses routes mainly by **number of hops**; simple and suited to small networks|

**IN SIMPLE FORM**
- OSPPF → shortest/efficient path
- EIGRP → Cisco + multiple metrics
- BGP → internet/networks talking to networks
- RIP → fewest hops 



### NAT  ( Network Address Translation )
- allows many device with private IPs to share one public IP address access the internet

**Why NAT?**
- IPV4 address are limited. Instead of giving every device a public IP.
```
20 devices → 1 Public IP → Internet
```

**How NAT works?**
```
Laptop
192.168.0.129 : 15401
       ↓
     NAT Router
       ↓
212.3.4.5 : 19273
       ↓
   Web Server
```
- laptop uses private IP, but web server sees the router's Public IP 


---
**Note NAT**
- private IP → public IP 
- many devices can share one public IP 
- Nar router maintains a translation table 
- NAT commonly tracks connections using IP address + port numbers
