### Basic Packet Capture:

|Option|What it does|Example|
|---|---|---|
|`-i INTERFACE`|Capture on a specific interface|`tcpdump -i eth0`|
|`-i any`|Capture on **all interfaces**|`tcpdump -i any`|
|`-w FILE`|Save packets to a `.pcap` file|`tcpdump -i eth0 -w data.pcap`|
|`-r FILE`|Read a saved capture file|`tcpdump -r data.pcap`|
|`-c COUNT`|Capture only a specific number of packets|`tcpdump -c 50`|
|`-n`|Don't resolve IP addresses to domain names|`tcpdump -n`|
|`-nn`|Don't resolve IP addresses **or port numbers**|`tcpdump -nn`|
|`-v`|Show more packet details|`tcpdump -v`|
|`-vv / -vvv`|Show even more details|`tcpdump -vv`|
###### Code:
```
# Capture 50 packets from eth0
sudo tcpdump -i eth0 -c 50

# Capture and save to file
sudo tcpdump -i eth0 -w data.pcap

# Read saved capture
tcpdump -r data.pcap

# Capture on all interfaces without name/port resolution
sudo tcpdump -i any -nn

# Capture with more details
sudo tcpdump -i eth0 -c 50 -v
```

[^1]Points To Remember:

[^1]: **`tcpdump` = Capture → Save → Read → Filter/Display**
	
	- **Interface:** `-i` → _Where to capture?_
	- **Write:** `-w` → _Save capture_
	- **Read:** `-r` → _Open saved capture_
	- **Count:** `-c` → _How many packets?_
	- **Numbers:** `-n` / `-nn` → _Don't translate addresses/ports_
	- **Verbose:** `-v` → _More details_


### Filtering Expressions
|Filter|Meaning|Example|
|---|---|---|
|`host IP`|Traffic **to/from** a host|`tcpdump host 192.168.1.10`|
|`src host IP`|Traffic **from** a host|`tcpdump src host 192.168.1.10`|
|`dst host IP`|Traffic **to** a host|`tcpdump dst host 192.168.1.10`|
|`port PORT`|Traffic **to/from** a port|`tcpdump port 53`|
|`src port PORT`|Traffic **from** a port|`tcpdump src port 53`|
|`dst port PORT`|Traffic **to** a port|`tcpdump dst port 53`|
|`tcp`|TCP traffic only|`tcpdump tcp`|
|`udp`|UDP traffic only|`tcpdump udp`|
|`icmp`|ICMP traffic only|`tcpdump icmp`|
|`ip`|IPv4 traffic|`tcpdump ip`|
|`ip6`|IPv6 traffic|`tcpdump ip6`|
###### Logical Operators
|Operator|Meaning|Example|
|---|---|---|
|`and`|**Both** conditions|`tcpdump host 1.1.1.1 and tcp`|
|`or`|**Either** condition|`tcpdump udp or icmp`|
|`not`|**Exclude** condition|`tcpdump not tcp`|
***IMPORTANT CODE**
```
# SSH traffic (TCP port 22)
tcpdump -i any tcp port 22

# NTP traffic (UDP port 123)
tcpdump -i wlo1 udp port 123

# HTTPS traffic to/from example.com
tcpdump -i eth0 host example.com and tcp port 443 -w https.pcap

# Read a capture file and show first 5 packets
tcpdump -r traffic.pcap -c 5 -n

# Count packets from a specific source IP
tcpdump -r traffic.pcap src host 192.168.124.1 -n | wc
```

==NOTE:==
**Host → Who?**  
`host`, `src host`, `dst host`

**Port → Which service?**  
`port`, `src port`, `dst port`

**Protocol → What type?**  
`tcp`, `udp`, `icmp`, `ip`, `ip6`

**Combine → `and`, `or`, `not`**

**Most useful pattern:**  
`tcpdump -i INTERFACE [FILTER] -n`


### Advanced Filtering
- find very specific packets in large packet captures

|Filter / Concept|Meaning|Example|
|---|---|---|
|`greater LENGTH`|Packet length ≥ specified size|`greater 1000`|
|`less LENGTH`|Packet length ≤ specified size|`less 100`|
|`proto[expr:size]`|Examine specific header bytes|`ip[0]`|
|`tcp[tcpflags]`|Examine TCP flags|`tcp[tcpflags]`|
|`==`|Exactly equal|`tcp[tcpflags] == tcp-syn`|
|`&`|Binary AND — check if a flag is set|`tcp[tcpflags] & tcp-syn != 0`|
|`\|`|Binary OR — match either flag|`tcp-syn\|tcp-ack`|
|`!`|Binary NOT — invert bits|`!`|

###### TCP Flags 
|Flag|Meaning|
|---|---|
|`tcp-syn`|Start TCP connection|
|`tcp-ack`|Acknowledge received data|
|`tcp-fin`|Finish/close connection|
|`tcp-rst`|Reset connection|
|`tcp-push`|Push data to application|
##### CODE 
```
# ONLY SYN packets
tcpdump "tcp[tcpflags] == tcp-syn"

# Packets with SYN flag set
tcpdump "tcp[tcpflags] & tcp-syn != 0"

# Packets with SYN OR ACK flag set
tcpdump "tcp[tcpflags] & (tcp-syn|tcp-ack) != 0"
```


##### Binary Operations 
|Operation|Meaning|Result|
|---|---|---|
|`&`|AND|`1` only when **both are 1**|
|`\|`|OR|`1` when **either is 1**|
|`!`|NOT|**Inverts** 0 ↔ 1|

###### Understanding the Difference?
**`==`** → _Only this flag_
`tcp-syn` = SYN is set, **all other flags unset**
**`&`** → _Does this flag exist?_
`& tcp-syn != 0` = SYN is set, **other flags may also be set**


### Displaying Packets
- how captured packets are displayed

| Option | Meaning                             | Use when                           |
| ------ | ----------------------------------- | ---------------------------------- |
| `-q`   | **Quick** output; brief information | Want a short summary               |
| `-e`   | Show **link-level/MAC headers**     | Need MAC addresses / Ethernet info |
| `-A`   | Show packet data as **ASCII**       | Looking for readable text          |
| `-xx`  | Show packet data in **hexadecimal** | Need raw packet bytes              |
| `-X`   | Show **hex + ASCII** together       | Need both formats                  |

##### CODE:
```
# Brief output
tcpdump -r file.pcap -q

# Show MAC addresses
tcpdump -r file.pcap -e

# Show readable ASCII data
tcpdump -r file.pcap -A

# Show hexadecimal data
tcpdump -r file.pcap -xx

# Show hexadecimal + ASCII
tcpdump -r file.pcap -X
```

***Points To Remember:***
`-q` → Quick
`-e` → Ethernet/MAC  
`-A` → ASCII  
`-xx` → Hex  
`-X` → Hex + ASCII
