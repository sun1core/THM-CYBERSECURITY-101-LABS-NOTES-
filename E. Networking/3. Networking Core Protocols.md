
### DNS: Remembering Address
```
nslookup example.com
```
→ Finds IP address/DNS information of a admin.

- Domain Name system → converts domain names → IP address
- OSI layer 7 → Application 
- Ports → UDP 53 ( default ), TCP 53 ( Fallback )

###### DNS Records 

| Record    | Purpose                       | Example                                |
| --------- | ----------------------------- | -------------------------------------- |
| **A**     | Domain → **IPv4** address     | `example.com` → `93.184.215.14`        |
| **AAAA**  | Domain → **IPv6** address     | `example.com` → `2606:2800:...`        |
| **CNAME** | Domain → **another domain**   | `www.example.com` → `example.com`      |
| **MX**    | Specifies the **mail server** | `test@example.com` → finds mail server |


### WHOIS 
```
whois example.com
```

→ Person or company registers a domain control its DNS records (A, AAAA, MX ) also, registration details.


### HTTP/S 
- Hypertext Transfer Protocol/Secure
- used for communication between browser( Client ) ↔ web server 
- HTTP ( 80 ), HTTPS ( 443 ), HTTPS ( 8080 ), HTTPS ( 8443 )

###### HTTPS Method Table 
|Method|Purpose|Example|
|---|---|---|
|**GET**|Retrieve data|Get a webpage/image|
|**POST**|Submit/send new data|Submit a form/upload|
|**PUT**|Create or update/overwrite resource|Update a file|
|**DELETE**|Delete a resource|Delete a file|
###### HTTP with Telnet 
- manually communicate with a web server by using telnet 
```
GET / HTTP/1.1
Host: anything
```
- to request a file;
```
GET / HTTP/1.1
Host: anything
```



### FTP: Transferring Files 
- to transfer files between a client and server 
- data transfer used as a separate connection 
- TCP port: 21 
- designed for file transfer and can be efficient compared with HTTP

###### FTP Commands 
| Command  | Purpose                 | Easy Meaning   |
| -------- | ----------------------- | -------------- |
| **USER** | Enter username          | Login user     |
| **PASS** | Enter password          | Login password |
| **RETR** | Download a file         | **Get** file   |
| **STOR** | Upload a file           | **Store** file |
| **LIST** | Show directory contents | **List** files |
***Example command**

|Command|Purpose|
|---|---|
|`ftp <IP>`|Connect to FTP server|
|`ls`|List available files|
|`type ascii`|Switch to ASCII/text mode|
|`get file.txt`|Download file|
|`quit`|Exit FTP|


### SMTP ( Simple Mail Transfer Protocol ): Sending Email 
- used to send emails
- TCP port 25
- Communication between:
    - Mail client → Mail server
    - Mail server → Mail server

###### SMTP Commands

| Command         | Purpose                     | Easy Meaning |
| --------------- | --------------------------- | ------------ |
| **HELO / EHLO** | Start SMTP session          | **Hello**    |
| **MAIL FROM**   | Specify sender              | **From**     |
| **RCPT TO**     | Specify recipient           | **To**       |
| **DATA**        | Start sending email content | **Message**  |
| `.`             | End email message           | **Finish**   |
| **QUIT**        | Close connection            | **Exit**     |


### POP3 ( Post Office Protocol Version 3 ): Receiving Email
- unencrypted by default, so someone capturing network traffic could potentially see the username, password and email contents.
- TCP Port: 110
- used to retrieve or download emails from a mail server to a mail client.


###### POP3 Commands 

|Command|Purpose|Easy Meaning|
|---|---|---|
|**USER**|Identify username|**Login user**|
|**PASS**|Provide password|**Login password**|
|**STAT**|Show number/total size of messages|**Status**|
|**LIST**|List messages and sizes|**List**|
|**RETR**|Retrieve a message|**Download**|
|**DELE**|Mark message for deletion|**Delete**|
|**QUIT**|End session and apply changes|**Exit**|



### IMAP ( Internet Message Access Protocol ): Synchronizing Email
- used to access and synchronize emails across multiple devices 
- TCP 143
- best for using email on multiple devices 
- Emails are kept on the server and synchronized 

###### IMAP Commands 
| Command    | Purpose               | Easy Meaning      |
| ---------- | --------------------- | ----------------- |
| **LOGIN**  | Authenticate user     | **Login**         |
| **SELECT** | Select mailbox/folder | **Choose folder** |
| **FETCH**  | Retrieve email data   | **Get email**     |
| **MOVE**   | Move messages         | **Move**          |
| **COPY**   | Copy messages         | **Copy**          |
| **LOGOUT** | End session           | **Exit**          |
