

### Active Directory 
- core of any windows domain 

###### Users 
- security principles 
- resources like files and printers 
- two types of entities;
    - people 
    - services 


###### Machines 
- passwords are automatically rotated out and also comprised 120 random characters 
- computer name usually followed by `$`  Example ```DC01$```



###### Security Groups 

| **Security Group**     | **Short Description**                                                         |
| ---------------------- | ----------------------------------------------------------------------------- |
| **Domain Admins**      | Full administrative control over the entire domain.                           |
| **Server Operators**   | Can administer Domain Controllers, but cannot modify admin group memberships. |
| **Backup Operators**   | Can access files for backup purposes, even without normal permissions.        |
| **Account Operators**  | Can create and modify domain user accounts.                                   |
| **Domain Users**       | Contains all user accounts in the domain.                                     |
| **Domain Computers**   | Contains all computer accounts in the domain.                                 |
| **Domain Controllers** | Contains all Domain Controller computer accounts.                             |
